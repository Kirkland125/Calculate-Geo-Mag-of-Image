"Object Length in Pixels" means to measure an object in the image, like an IQI or lead letter, and enter that value in pixels into the box.
"Pixel Pitch" is the detector's pixel pitch, in microns, not a measurement from the image.
"Actual Object Length" is that same object's real-world size, in microns. For example, a 1.5" IQI wire should be entered as 38100 microns.
